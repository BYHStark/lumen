# progress.md 格式

保持这几个标题，不要改成散文。未知就写「未知」，不要猜。

```markdown
# 进度

- 更新：YYYY-MM-DD
- 阶段：0
- 状态：未开始 | 进行中 | 等待用户 | 阶段完成
- 本机 Go：从 `go version` 读到的版本

## 已完成

- 条目。证据写测试名、命令或提交，没有证据就不要列。

## 现在

一句说清用户正在做的那一小步。

## 下一步

一个动作，不要列一串。

## 未决

- 没有就写「无」。

## 跳过的验收

- 没有就写「无」。写明是用户要求跳过，还是尚未做到。
```

阶段完成的标准在 `docs/curriculum.md`。测试没覆盖规定的失败场景时，状态保持「进行中」。
